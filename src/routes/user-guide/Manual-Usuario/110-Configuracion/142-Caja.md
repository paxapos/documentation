# Caja

<div id="caja"></div>

> **¿Dónde está en el sistema?:** Menú principal → **Configuración** → **Operación** → **Caja**  
> **¿Quién lo usa?:** Dueños y administradores del comercio

---

## 🎯 ¿Qué es y para qué sirve esta pantalla?

<div id="que-es-y-para-que-sirve-esta-pantalla"></div>

Define si tu comercio usa el **arqueo de caja clásico** o el **nuevo arqueo**, que obliga a abrir una caja antes de cobrar o registrar movimientos.

![Pantalla de Caja](images/manual/configuracion-general/10-caja.png)

> Esta sección solo aparece si el módulo **Arqueo de Caja** está activo (ver [Módulos](/user-guide/modulos)).

---

## 🔑 Requisitos para empezar a usarlo

<div id="requisitos-para-empezar-a-usarlo"></div>

- Tener el permiso de **Configuración del comercio** configurado en [Permisos por Rol](/user-guide/permisos-por-rol).
- Tener activo el módulo **Arqueo de Caja**.

---

## 🎨 Campos: ¿Qué es cada cosa?

<div id="campos-que-es-cada-cosa"></div>

| Campo | ¿Qué es? |
|---|---|
| **Usar la nueva versión de arqueo** | Con esto activo, los movimientos de caja nacen dentro de un arqueo abierto obligatorio: aparece el botón "Abrir Caja" en la adición y no se puede cobrar ni registrar movimientos sin un arqueo abierto. Desactivado, se usa el arqueo clásico (sin ese requisito). |

---

## 📑 Guía Paso a Paso: ¿Cómo se usa?

<div id="guia-paso-a-paso-como-se-usa"></div>

### Paso 1: Activar el nuevo arqueo

<div id="paso-1-activar-el-nuevo-arqueo"></div>

1. Andá a **Configuración → Caja**.
2. Activá **Usar la nueva versión de arqueo**.
3. Tocá **Guardar**.
4. A partir de ahora, cada turno tiene que abrir una caja antes de poder cobrar.

---

## ⚠️ ¿Qué hacer si algo no sale bien? (Problemas Comunes)

<div id="que-hacer-si-algo-no-sale-bien-problemas-comunes"></div>

| ¿Qué te pasa? | ¿Por qué puede ser? | ¿Cómo se soluciona? |
|---|---|---|
| El personal no puede cobrar y pide "Abrir Caja". | Activaste el **nuevo arqueo**: ahora hace falta un arqueo abierto para cobrar. | Es el comportamiento esperado — pedile al mozo/cajero que abra la caja al empezar el turno. Si no querés este requisito, desactivá la opción. |
| No veo esta sección. | El módulo Arqueo de Caja está apagado. | Activalo en [Módulos](/user-guide/modulos). |
