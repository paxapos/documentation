# Agregar Producto al Menú

> **Dónde está:** Productos → **Menú** → botón **➕ Agregar Producto**
> **Para qué sirve:** crea un producto de venta y lo publica en el menú activo.
> **Quién lo usa:** encargados de carta, administradores.

---

## 🧭 Antes de entrar acá

Este formulario es la vía principal para **crear un producto de venta**. Se completa en tres pasos, y el sistema los muestra numerados en pantalla.

Conviene tener listo:

| Lo que vas a necesitar | Dónde se configura |
|---|---|
| La **categoría** donde va a aparecer | [Categorías](/user-guide/categorias) |
| Las **variantes**, si el producto las lleva | [Variantes](/user-guide/variantes-grupo-sabores) |
| La **impresora** y el **puesto (KDS)** del producto | Configuración → Impresoras · Comandero → Puestos |

---

## ▶️ Paso 1: Información Básica (obligatoria)

Son los datos mínimos para poder agregar el producto:

| Campo | Qué es |
|---|---|
| **Producto** | El producto que estás agregando. Si venís desde el maestro, viene precargado y no se puede cambiar acá. |
| **Categoría** ⃰ | Dónde aparecerá dentro del menú. |
| **Precio de Venta** ⃰ | Cuánto se le cobra al cliente. |
| **Moneda** | La moneda del precio (por defecto, Peso argentino). |
| **Impuesto / IVA** | La alícuota impositiva del producto (0%, 2,5%, 5%, 10,5%, 21%, 27%). |

---

## ▶️ Paso 2: Variantes del producto

Las variantes son las opciones que el cliente puede elegir al pedir este producto: sabores, tamaños, agregados.

Marcá las variantes que apliquen. Si te falta alguna, se crea desde [Variantes](/user-guide/variantes-grupo-sabores) y después volvés acá.

---

## ▶️ Paso 3: Configuración Operativa

Define por dónde se despacha el producto:

| Campo | Qué es |
|---|---|
| **¿Dónde se imprime la comanda?** | La impresora del sector (Cocina, Barra, Parrilla…). |
| **Puesto (KDS)** | La pantalla de cocina donde se muestra el pedido. |

---

## ⚙️ Opciones adicionales y avanzadas

Al pie del formulario hay dos bloques que se despliegan tocándolos:

- **Opciones Adicionales:** el **Orden** de aparición y el **Nombre en Ticket**.
- **Modificar Producto Maestro:** editá los datos de fondo del producto (nombre, código de barras, imagen, stock, descripción) sin salir de esta pantalla.

---
